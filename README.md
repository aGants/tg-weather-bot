# 🌤️ TG Weather Bot - Умный бот для рекомендаций по одежде

**Telegram бот, который анализирует погоду и дает советы, что надеть, учитывая текущие условия и прогноз изменений.**

## ✨ Возможности

### ✨ **Анализ погоды**
- **Предупреждения о дожде** - предупреждает о вероятности осадков в ближайшие часы
- **Изменения температуры** - уведомляет о значительных перепадах (более 10°C)
- **Изменения ветра** - сообщает об усилении или ослаблении ветра

```
└── index.js                   # Точка входа
```

## 🔧 **Основные функции**

### 📍 **Определение города**
- **Геолокация** - автоматическое определение по GPS
- **Ручной ввод** - ввод названия города вручную
- **Умное сохранение** - запоминает город и координаты

### 🌡️ **Анализ погоды**
- **Текущая погода** - температура, влажность, ветер, УФ-индекс
- **Качество воздуха** - AQI с рекомендациями
- **Прогноз изменений** - предупреждения о дожде, температуре, ветре
- **Рекомендации по одежде** - с учетом температуры и типа погоды


## 📱 **Команды бота**

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню выбора способа определения города |
| `/what_to_wear` | Получить рекомендации по одежде для сохраненного города |
| `/share_location` | Поделиться геолокацией |
| `/manual_city` | Ввести название города вручную |


## 🎯 **Логика предупреждений**

### **Дождь (вероятность > 50%)**
- Проверяет, не идет ли уже дождь
- Анализирует ближайшие 12 часов
- Показывает время и вероятность

### **Изменения температуры (> 10°C)**
- Сравнивает с текущей температурой
- Использует дневные минимум/максимум
- Предупреждает о будущих изменениях

### **Изменения ветра**
- Анализирует ближайшие 6 часов
- Определяет изменение уровня ветра
- Показывает время и направление изменения

## 🚀 **Установка и запуск**

### **Требования**
- Node.js 16+
- npm или yarn
- Telegram Bot Token

### **Установка**
```bash
# Клонирование репозитория
git clone https://github.com/your-username/tg-weather-bot.git
cd tg-weather-bot

# Установка зависимостей
npm install

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте .env файл

# Запуск бота
npm start
```

### **Переменные окружения**
```env
BOT_API_KEY=your_telegram_bot_token
NODE_ENV=development

# Только для продакшена: если задан WEBHOOK_URL, бот работает через webhook
# вместо long-polling (см. раздел "Деплой на Render" ниже).
# WEBHOOK_URL=https://your-app.onrender.com
# WEBHOOK_SECRET=some_random_string
```
